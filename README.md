# DSA Practice

Solving data structures and algorithms problems in Java, organized by topic.
Following a structured roadmap (Striver's A2Z sheet) topic by topic, with extra
practice problems and pattern-based revision layered in later.

## Structure
Each folder is a topic. Each file is one problem, named after it, with a short
comment at the top covering approach, time complexity, and space complexity.
